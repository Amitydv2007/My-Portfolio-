## 🚀 One-Click Deployment to Vercel

### Deploy with GitHub + Vercel (Recommended):
1. Create a repository on GitHub (e.g. `amit-kumar-portfolio`).
2. Push your project files:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of modern interactive portfolio"
   git branch -M main
   git remote add origin https://github.com/Amitydv2007/amit-kumar-portfolio.git
   git push -u origin main
   ```
3. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
4. Select your GitHub repository `Amitydv2007/amit-kumar-portfolio`.
5. Click **Deploy**! Your site is live instantly with an automatic SSL URL like `https://amit-kumar-portfolio.vercel.app`.
